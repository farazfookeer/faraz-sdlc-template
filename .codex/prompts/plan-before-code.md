# Plan before code

Work on **[ISSUE/REQUIREMENT]**.

Do not modify files yet. Read `AGENTS.md`, the requirement, relevant architecture and test strategy, then inspect the affected code and tests.

Return:

1. your understanding of the outcome and acceptance criteria;
2. current behaviour and affected components;
3. a small, ordered implementation plan and expected files;
4. security, privacy, compatibility, migration and operational risks;
5. tests to add or update and validation commands;
6. ambiguities or assumptions needing approval.

Keep the plan within the stated scope. Wait for approval before implementation.
