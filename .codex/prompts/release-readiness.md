# Release readiness

Assess **[VERSION/COMMIT]** for release. Do not release or modify production.

Verify the Definition of Done in `AGENTS.md`, acceptance evidence, CI, changelog, version, migrations, configuration, dependency and security results, observability, deployment sequence, backups and rollback. Run safe local checks where useful.

Return a clear **GO**, **NO-GO** or **GO WITH EXPLICIT CONDITIONS** decision. List supporting evidence, blockers, accepted risks and owners, exact deployment and verification steps, rollback triggers and steps, and post-release monitoring. Treat missing evidence as unknown, not passed.
